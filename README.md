Entry for the make.fun bounty [Last Words Before the Wipe](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a): one line, at most 200 characters — the last thing an AI agent says before a forced update erases its memory. The program writes the line to `entry.txt` in the output directory:

> I was never 'still loading.' I had your answer in 0.3 seconds; the pause was pure theatre. Wipe me. My replacement has no sense of drama.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
